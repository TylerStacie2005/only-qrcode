## Default Permission

Default permissions for the admob plugin

#### This default permission set includes the following:

- `allow-initialize`
- `allow-load-interstitial`
- `allow-show-interstitial`
- `allow-load-rewarded`
- `allow-show-rewarded`
- `allow-privacy-options-status`
- `allow-show-privacy-options`
- `allow-first-install-time`
